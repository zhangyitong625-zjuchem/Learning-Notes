## 1 宏观自由度与基本变量
### 1.1 宏观自由度
#### 1.1.1 只有外源自由度（只处理做功和传热）
系统-环境相互作用,系统内部——$dU=dq+dW=-T_{环}dS_环-P_{外}dV$——对应环境
系统内部：对应两个外源自由度$(V,S)$ 即$U=f(V,S)$
全微分：$dU=\left( \dfrac{ \partial U }{ \partial S } \right)_{V,n}dS+\left( \dfrac{ \partial U }{ \partial V } \right)_{S,n}dV$
而有$dU=TdS-PdV$，可知$\left( \dfrac{ \partial U }{ \partial S } \right)_{V,n}=T,\left( \dfrac{ \partial U }{ \partial V } \right)_{S,n}=-P$
#### 1.1.2 考虑内秉自由度
对于多个自由度：$U=f(S,V,n_{1},n_{2},\dots,n_{c})$，其组成是——两个外源自由度+c个组分带来的c个内秉自由度，总自由度$F=2+c$
e.g. PV=nRT， 确定P,V,n三个自由度，就可以确定一个状态
### 1.2 基本自变量
外源自由度：$(T,S),(P,V)$
内秉自由度：$(\mu_{i},n_{i})$
对$dn_{i}=0$的经典热力学系统（热机系统，只处理做功和传热）有
$$
\begin{align}
U\to(V,S) \\
H\to(V,T) \\
A\to(P,S) \\
G\to(P,T)
\end{align}
$$
是对上面的外源自由度的组合（一个强度性质+一个广度性质）
对H有：$dH=d(U+PV)=TdS-PdV+PdV+VdP=TdS+VdP$
则$\left( \dfrac{ \partial H }{ \partial S } \right)_{P,n}=T,\left( \dfrac{ \partial H }{ \partial P } \right)_{S,n}=V$
对A：$dA=d(U-TS)=TdS-PdV-TdS-SdT=-SdT-PdV$
则$\left( \dfrac{ \partial A }{ \partial V } \right)_{T,n}=-S,\left( \dfrac{ \partial A }{ \partial T } \right)_{V,n}=-P$
对G：$dG=d(H-TS)=TdS+VdP-TdS-SdT=VdP-SdT$
则$\left( \dfrac{ \partial G }{ \partial P } \right)_{T,n}=V,\left( \dfrac{ \partial G }{ \partial T } \right)_{P,n}=-S$
## 2 热力学基本方程
### 2.1 基本方程
$$
dU=TdS-PdV
$$
### 2.2 麦克斯韦关系式
$g=f(x,y)$
$dg=\left( \dfrac{ \partial g }{ \partial x } \right)_{y}dx+\left( \dfrac{ \partial g }{ \partial y } \right)_{x}dy=\mathbf{X}dx +\mathbf{Y}dy$
则$\left( \dfrac{ \partial \mathbf{X} }{ \partial y } \right)_{x}=\left( \dfrac{ \partial \mathbf{Y} }{ \partial x } \right)_{y}$
*由此，可以根据这个来记忆： 斜对角位置一定是一组自由度*
### 2.3 压强、力、熵
$$
P=-\left( \dfrac{ \partial A }{ \partial V } \right)_{T,n}=-\left( \dfrac{ \partial (U-TS) }{ \partial V } \right)_{T,n}=-\left( \dfrac{ \partial U }{ \partial V}  \right)_{T,n}+T\left( \dfrac{ \partial S }{ \partial V }  \right)_{T,n}
$$
对于一个活塞系统
![[Pasted image 20250616120459.png|150]]
$$
\vec{F}=a\vec{P}=-\left( \dfrac{ \partial U }{ \partial V/a}  \right)_{T,n}+T\left( \dfrac{ \partial S }{ \partial V/a }  \right)_{T,n}=\left[ -\left( \dfrac{ \partial U }{ \partial x}  \right)_{T,n}+T\left( \dfrac{ \partial S }{ \partial x }  \right)_{T,n} \right]\vec{x}_{0}
$$
第一项是内能的梯度，是经典力；第二项是“熵”力
### 2.4 理想气体的性质
#### 2.4.1 $dU=C_{V}dT$
回到$P=-\left( \dfrac{ \partial A }{ \partial V } \right)_{T,n}=-\left( \dfrac{ \partial U }{ \partial V}  \right)_{T,n}+T\left( \dfrac{ \partial S }{ \partial V }  \right)_{T,n}$
$\left( \dfrac{ \partial U }{ \partial V}  \right)_{T,n}=T\left( \dfrac{ \partial S }{ \partial V }  \right)_{T,n}-P=T\left( \dfrac{ \partial P }{ \partial T } \right)_{V,n}-P=T\cdot \cfrac{nR}{V}-P\ce{#}0$
所以对于理想气体，有
$$
P=T\left( \dfrac{ \partial S }{ \partial V }  \right)_{T,n}
$$
解释:*膨胀让熵增加，所以压强大会膨胀*
（可以推出$dU=C_{v}dT$）
对于F
$$
\vec{F}=T\left( \dfrac{ \partial S }{ \partial x }  \right)_{T,n}\vec{x}_{0}
$$
即*膨胀是“熵力”推动的*
#### 2.4.2 $dH=C_{P}dT$
证明$dH=C_{p}dT$
$H=f(P,T)$
$dH=\left( \dfrac{ \partial H }{ \partial T } \right)_{P,n}dT+\left( \dfrac{ \partial H }{ \partial P } \right)_{T,n}dP$
$\left( \dfrac{ \partial H }{ \partial P } \right)_{T,n}=\left( \dfrac{ \partial (G+TS) }{ \partial P } \right)_{T,n}=\left( \dfrac{ \partial G }{ \partial P } \right)_{T,n}+T\left( \dfrac{ \partial S }{ \partial P } \right)_{T,n}=V-T\cdot \cfrac{nR}{P}=0$

## 3 摩尔数可变系统的基本方程
### 3.1 化学势与热力学基本方程
$$
U=f(S,V,n_{1},\dots n_{c})
$$
则有
$dU=\left( \dfrac{ \partial U }{ \partial S } \right)_{V,n}dS+\left( \dfrac{ \partial U }{ \partial V } \right)_{S,n}dV+\sum_{i=1}^c \left( \dfrac{ \partial U }{ \partial n_{i} } \right)_{V,S,n\neq n_{i}}dn_{i}$
则第一项是T，第二项是P，第三项也一定是一个强度性质，它的条件是除了$n_{i}$之外，其他摩尔数不变
定义出化学势
>[!note] 化学势
>$$\mu_{i}=\left( \dfrac{ \partial U }{ \partial n_{i} }  \right)_{S,V,n\neq n_{i}}$$

有相关的表达式
$$
\begin{align}
dU=TdS-PdV+\sum_{i=1}^c \mu_{i} dn_{i} \\
dH=TdS+VdP+\sum_{i=1}^c \mu_{i}dn_{i} & \implies \mu_{i}=\left( \dfrac{ \partial H }{ \partial n_{i} }  \right)_{S,P,n\neq n_{i}} \\
dA=-SdT-PdV+\sum_{i=1}^c\mu_{i}dn_{i} & \implies\mu_{i}=\left( \dfrac{ \partial A }{ \partial n_{i} }  \right)_{T,V,n\neq n_{i}} \\
dG=-SdT+VdP+\sum_{i=1}^c \mu_{i}dn_{i} & \implies \mu_{i}=\left( \dfrac{ \partial G }{ \partial n_{i} }  \right)_{T,P,n\neq n_{i}} \\
\end{align}

$$

称为基本方程
所有的偏导
这四个基本的全微分方程，一定要满足可逆过程（或近似可逆过程状态）因为如果不是这些状态，某些强度性质无法保持不变，求偏导也没有了什么意义。
但是，在实际的过程中，我们一定是要研究变化的。所以，只要一个过程的始末状态在可逆过程热力学里面有定义，那么就一定会有一个可逆过程符合上述的始末状态，因此就可以用它来求U、H、A、G.
### 3.2 麦克斯韦方程
G相关：
$\left( \dfrac{ \partial \mu_{i} }{ \partial P } \right)_{T,n}=\left( \dfrac{ \partial V }{ \partial n_{i} } \right)_{T,P,n\neq n_{i}};\quad -\left( \dfrac{ \partial \mu_{i} }{ \partial T } \right)_{P,n}=\left( \dfrac{ \partial S }{ \partial n_{i} } \right)_{T,P,n\neq n_{i}}$
A相关：
$-\left( \dfrac{ \partial \mu_{i} }{ \partial T } \right)_{V,n}=\left( \dfrac{ \partial S }{ \partial n_{i} } \right)_{T,V,n\neq n_{i}};\quad \left( \dfrac{ \partial \mu_{i} }{ \partial V } \right)_{P,n}=\left( \dfrac{ \partial P }{ \partial n_{i} } \right)_{T,V,n\neq n_{i}}$
H相关：
$\left( \dfrac{ \partial \mu_{i} }{ \partial P } \right)_{S,n}=\left( \dfrac{ \partial V }{ \partial n_{i} } \right)_{S,P,n\neq n_{i}};\quad \left( \dfrac{ \partial \mu_{i} }{ \partial S } \right)_{P,n}=\left( \dfrac{ \partial T }{ \partial n_{i} } \right)_{S,P,n\neq n_{i}}$
U相关：
$\left( \dfrac{ \partial \mu_{i} }{ \partial S } \right)_{V,n}=\left( \dfrac{ \partial T }{ \partial n_{i} } \right)_{S,V,n\neq n_{i}};\quad -\left( \dfrac{ \partial \mu_{i} }{ \partial V } \right)_{S,n}=\left( \dfrac{ \partial P }{ \partial n_{i} } \right)_{S,V,n\neq n_{i}}$
### 3.3 理想气体（纯态）的化学势
衡量摩尔数变化是否达到平衡——用化学势表征
就要把$G$写成摩尔数的函数。
写成$G=n G_{m}$，称$G_{m}$为摩尔自由能
$\mu=\left( \dfrac{ \partial G }{ \partial n } \right)_{T,P}=G_{m}$
给定T下，求$\mu$随P的变化
$\left( \dfrac{ \partial \mu }{ \partial P } \right)_{T}=\left( \dfrac{ \partial V }{ \partial n } \right)_{P,T}=\cfrac{RT}{P}$
则$(d\mu)_{T}=\cfrac{RT}{P}dP$
积分得到标准态（任意T下压强总是1bar，即$P^0\ce{#} 1\pu{ bar }$的时候）的化学势:
$$
\mu=\mu^0+RT\cdot \ln \cfrac{P}{P^0}
$$
对理想气体： $P=\cfrac{nRT}{V}=cRT$,$\mu=\mu^0+RT\cdot \ln \cfrac{c}{c^0}$
因此给定T下，浓度增加则$\mu$增加

>[!example] 吉布斯佯谬
>![[Pasted image 20250616155219.png|100]]
>等温的左右两个箱子，刚性导热，把活塞向上提一点，打开一条缝
>此时$dS_{左}=\cfrac{dU}{T}+\cfrac{P}{T}dV_{左}-\cfrac{1}{T}\mu_{左}dn_{左}$
>由于温度不变，内能不变，且体积不变，因此$dS_{左}=-\cfrac{\mu_{左}}{T}dn_{左}$，$dS_{右}=-\cfrac{\mu_{右}}{T}dn_{右}$
>$dS=\cfrac{1}{T}(\mu_{左}-\mu_{右})d\xi=\cfrac{1}{T}\ln \cfrac{c_{左}}{c_右} d\xi$
>若$c_{左}>c_{右}，则\mu_{左}>\mu_{右}，d\xi=dn_{左}<0$
>若$c_{左}<c_{右}，则\mu_{左}<\mu_{右}，d\xi=dn_{左}>0$
>则$\left( \dfrac{ \partial S }{ \partial \xi } \right)_{U,V}=0 \implies \mu_{左}=\mu_{右}\implies c_{左}=c_{右}$
>因此这个模型是一个扩散过程

### 3.4 摩尔数变化的第二定律($dW_{非}=0$)
T,P给定条件下$0\geq dG=-SdT+VdP+\sum_{i}\mu_{i}dn_{i}$
同理其他的情况都一样
$(T,P)or(T,V)or(S,P)or(S,V)$给定时，第二定律均可表述为
$$\sum_{i=1}^c\mu_{i}dn_{i}\leq 0$$

### 3.5 考虑非体积功的情况，$dW_{非}\neq 0$
同理可以推导出温度和压强给定时（T，P）一定，$dG\leq dW_{非}$是第二定律的表述
而$W_{非}$也可以分为**可逆的非体积功**和**不可逆的非体积功**
可逆时，$dG=dW_{非}$（取等条件）
## 4 量子统计热力学与可逆过程热力学
### 4.1 处理角度
1. 可逆过程热力学（宏观热力学）注重过程，对状态几乎无法描述
2. 量子统计热力学从状态描述出发，而不关注过程
3. 处理的过程，二者完全一致
### 4.2 配分函数与热力学状态函数
$$
\begin{align}
A & =U-TS=U(0)+Q-TS \\
 & =U(0)+nRT \cfrac{d(\ln f_{总})}{dT}-T\left( \cfrac{Q}{T}-nR\ln f_{总} \right) \\
 & =U(0)-nRT\ln f_{总} \\
\Delta A & =-nRT\ln \cfrac{f_{总末}}{f_{总始}}
\end{align}
$$

$$
P=\left( \dfrac{ \partial A }{ \partial V }  \right)_{T,n}=\left( \dfrac{ \partial U(0) }{ \partial V }  \right)_{T,n}+nRT\left( \dfrac{ \partial \ln f_{总} }{ \partial V }  \right)_{T,n}
$$
